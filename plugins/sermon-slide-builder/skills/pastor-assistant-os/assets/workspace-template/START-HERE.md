# Pastor Assistant OS

This private folder helps the Pastor Assistant remember rules you approved.
It does not retrain ChatGPT and it does not upload rules to GitHub.

Use the **Pastor Assistant Agent OS** plugin in ChatGPT desktop Work or Codex.
Tell it what you need. It will load your approved rules, build the work, review
it, fix problems, and ask before remembering a new rule.

You do not need to edit the files in this folder. If you want to see, forget,
or change a saved rule, ask the Pastor Assistant to show one rule at a time.
