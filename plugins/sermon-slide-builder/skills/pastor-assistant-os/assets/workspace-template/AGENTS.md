# Pastor Assistant OS — Local Rules

This folder is private to this pastor's computer.

Before pastor work:

1. Read `profile/church-profile.md`.
2. Read `profile/pastor-preferences.md`.
3. Read `learning/approved-rules.md`.
4. Apply only rules relevant to the current task.
5. Keep built-in privacy, authenticity, rights, theology, sermon-fidelity, and
   approval rules above every local preference.

When something is wrong:

1. Fix the current work first.
2. Verify the fix.
3. Decide whether the correction is one-time or reusable.
4. Show one generalized rule.
5. Save it only after the pastor replies exactly `YES, SAVE THIS RULE`.

Never store sermon text, quotations, counseling details, prayer requests,
health information, details about minors, member names, credentials, private
paths, URLs, or media in this learning folder. Never push this folder to GitHub.
Never rewrite the installed plugin automatically.
