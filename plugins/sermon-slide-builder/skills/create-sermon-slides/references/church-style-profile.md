# Church Style Profile

Do not assume one church's screen, fonts, colors, Bible translation, or file
locations apply to another church. Use supplied pastor-approved files first.

## Resolve before the first production deck

Ask for only what the current task needs:

- a recent approved PowerPoint or blank church template;
- ordinary 16:9 or the exact dimensions of a special sanctuary screen;
- the usual content layout and text-safe area;
- the church's licensed fonts and whether they are installed;
- the current sermon-series colors or art;
- the default Bible translation when the note does not specify one;
- the approved location for sermon notes, photos, and finished files;
- whether an audience handout is part of the weekly workflow.

Do not collect passwords, account recovery codes, or private file-server
credentials in chat. Let the operating system or connected service handle sign
in.

## Canvas

- Preserve a supplied deck's exact dimensions and master.
- If the church has a special screen, use its exact ratio and safe zones.
- If there is no template and no special screen, use 16:9.
- Do not crop a 16:9 image blindly into ultrawide. Recompose it for each ratio.
- Preview on the actual presentation computer before the first service.

## Layout

- Inherit an approved deck before creating a new visual system.
- Treat recent pastor-approved sermon decks as the layout authority. Reuse their
  geometry, margins, type scale, and text/image frame positions—not their old
  sermon wording.
- When no layout precedent exists, use concise text on the left and one dominant
  image on the right for content slides.
- Keep one side assignment throughout the deck unless the pastor requests a
  deliberate exception.
- Keep text and images in separate regions. Never place sermon words over a
  photograph or generated image.
- Full-width art must be image-only. Full-width wording must be text-only or use
  a separate solid-color panel with no image behind it.
- Use large type, high contrast, generous margins, and crop-safe images.
- Never stretch an image to fill a frame; crop proportionally.

## Fonts and colors

- Use the fonts already present in the approved template.
- Confirm every referenced font is installed or embedded before final delivery.
- A missing font is a setup issue, not permission to shrink the text.
- Use the current sermon-series palette when one exists.
- Keep church logos proportional and use only pastor-approved versions.

## Scripture

- Preserve the translation written in the sermon note.
- If the note contains only a reference, use the church's documented default.
- If no default exists, ask the pastor before adding the passage.
- Never silently switch translations or repair theological wording.

## Local file locations

Each church chooses its own folders. Do not ship or hardcode private drive paths
in a public plugin. Ask the pastor to select folders through the operating
system, then store only non-secret configuration with permission.
