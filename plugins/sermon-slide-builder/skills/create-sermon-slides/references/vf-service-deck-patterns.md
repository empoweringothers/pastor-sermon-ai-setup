# VF Service Deck Patterns

Use this reference for the Valley Forge service-slide family. It was derived
from a read-only review of several recent pastor-edited sermon decks and a
matched ordinary-widescreen/sanctuary-screen pair. The public skill contains
only generalized layout rules; it does not contain sermon wording, private
photographs, or copied slide artwork.

The currently supplied, pastor-approved PowerPoint always outranks this
reference. Copy its layout system, never its old sermon content.

## Canvas families

- The primary sanctuary family is approximately `2560 × 704`, or `3.636:1`.
  Reviewed files used exact PowerPoint sizes including about `35.5608 × 9.7795`
  inches and `26.6667 × 7.3333` inches at that same ratio.
- This sanctuary canvas is close to, but not the same as, true `32:9`. Never
  round or convert an approved VF file to 32:9.
- Ordinary widescreen is `16:9`. Build it as a separate composition when both
  screen families are requested.
- Always read the uploaded PPTX dimensions and preserve them exactly. These
  measured values are fallback recognition aids, not permission to resize a
  template.
- Never infer the canvas from filename words such as `HD`, `UW`, or `32x9`.
  The reviewed paired files included names that contradicted their actual slide
  dimensions. The dimensions inside the PPTX always win.

## Repeated deck rhythm

Recent approved decks repeatedly use this rhythm:

1. a series-art opener or graphic-only first slide;
2. a sermon-title or section-title treatment;
3. text-only Scripture, quotation, or outline slides on the series background;
4. image-rich point slides with a dedicated text region and image region;
5. returns to the established text-only treatment when a new picture is not
   needed.

Do not add a picture to every slide. Visual eligibility follows the sermon
outline and the pastor's media directions.

## Image-rich content layout

- The dominant recent pattern is text on the left and one picture on the right:
  `39 of 42` reviewed mixed text-and-picture slides (`93%`) used that direction.
  Keep the side assignment stable; do not alternate merely for variety.
- In the reviewed sanctuary decks, the dominant picture usually occupied about
  `35–50%` of the slide width and commonly began around `52–61%` of the canvas
  width. Use the current deck's actual guides when available; these percentages
  are only a starting range for a new matching layout.
- Keep a visible gutter between the text frame and picture frame. A starting
  range of roughly `1–3%` of canvas width worked in the reviewed examples. Text
  must end before the picture begins.
- A right-side picture may run the full slide height or sit inside a deliberate
  framed crop, depending on the current series. Crop proportionally; never
  stretch.
- Preserve the series mark in its established small footer position. Do not let
  a new image cover it.
- Use one dominant image instead of several small decorative images unless the
  pastor's source slide explicitly calls for a real-photo collage.

Sermon text never goes over a topical photograph or AI illustration. A supplied
series texture or background may remain behind text only when it is already an
approved part of the template and was designed as the text field. Do not treat
that exception as permission to turn a new illustration into a text background.

## Typography and color

- Inherit the current deck first. Recent sanctuary decks commonly use
  `Visby CF Heavy` for primary copy and `Visby CF Medium` for supporting copy.
- Recent ultrawide examples commonly use roughly `60–96 pt` type, with smaller
  `44–54 pt` copy reserved for dense Scripture or supporting detail. Match the
  nearest approved slide; do not force a universal size or shrink copy merely
  to make it fit.
- Use the current sermon-series art and palette when supplied.
- If no series deck exists and VF defaults are explicitly requested, use the
  approved brand family: Navy `#001E4B`, Royal `#232D78`, Cobalt `#4A75FF`,
  Sky `#E1ECFF`, and Cream `#F8F0E1`. Use licensed Niveau Grotesk/Visby assets
  only when installed or embedded; ask before substituting fonts.
- Keep logo artwork proportional, unwarped, and in an approved blue or white
  treatment.

## Recompose instead of crop

When producing both sanctuary and 16:9 decks:

- preserve the same hierarchy, side assignment, series identity, and wording;
- resize and reposition text frames for each canvas;
- create a separate crop of every picture for each image frame;
- keep important faces and objects clear of sanctuary-screen seams and edges;
- render and inspect both files independently.

The widescreen file is not a crop of the sanctuary file, and the sanctuary file
is not a stretched widescreen file.

Do not reproduce the mechanical scale-down seen in one legacy paired example;
it reduced type and all objects to about half size and left excessive vertical
empty space. Rebuild the composition for the second canvas.

## What not to copy from old decks

Use reviewed service files as layout evidence only. Do not inherit old sermon
words, old citations, old factual claims, or old image choices. Some legacy
decks depict the same recurring biblical person with visibly different faces;
that is a continuity problem to correct with the current sermon-specific
character record, not a precedent to repeat.

Native rendering of the reviewed files also found legacy clipping/reflow,
text-media collisions, and stretched picture frames. None of the `76` reviewed
slides contained a `[Sources]` block. Those are defects to catch and correct,
not accepted VF standards. A reference deck controls style and geometry; it
does not waive final QA, provenance, or character-continuity requirements.
